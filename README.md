## 📖 Sobre o projeto

O **Blue Lock Team Builder** é uma aplicação web interativa inspirada no anime e mangá *Blue Lock*. Com ela, você escolhe personagens, monta uma escalação de futebol de até 11 jogadores, movimenta-os pelo campo e testa diferentes formações táticas. Também é possível gerenciar reservas e adicionar personagens personalizados.

> ⚠️ **Aviso:** o catálogo pode conter spoilers do mangá.

## ✨ Funcionalidades

- 🔎 Pesquisa de personagens pelo nome e filtro por equipe.
- 👥 Catálogo com personagens de várias equipes e fases de Blue Lock.
- ⚽ Escalação interativa com até **11 jogadores** no campo.
- 🖱️ Movimentação dos jogadores por arraste, com mouse, toque ou caneta.
- 📐 Formações táticas: **4-3-3**, **4-4-2**, **4-2-3-1** e **3-5-2**.
- 🪑 Banco de reservas para jogadores fora da escalação titular.
- ➕ Cadastro de personagens personalizados com nome, posição e foto opcional por URL HTTPS.
- 💾 Salvamento automático de escalações, reservas e personagens personalizados usando o armazenamento local do navegador.
- 📱 Layout responsivo, adaptado para diferentes tamanhos de tela.
- 🖼️ Uso de imagens alternativas ou iniciais quando a foto não carregar.

## 🕹️ Como usar

1. **Escolha um personagem** no catálogo à esquerda. Use a busca ou o filtro por equipe para encontrá-lo.
2. **Clique no personagem** para adicioná-lo ao campo (até 11 titulares).
3. **Selecione uma formação** e clique em **Organizar formação** para distribuir automaticamente os jogadores.
4. **Arraste os jogadores** pelo campo para ajustar as posições.
5. **Gerencie o banco de reservas:** quando o campo está cheio, personagens adicionais vão para a reserva. Clique no botão **×** de um jogador para retirá-lo do campo ou da reserva.
6. **Adicione personagens personalizados** pelo formulário do catálogo.
7. Para recomeçar, clique em **Limpar campo**. Os titulares serão movidos para o banco de reservas.

As alterações são salvas automaticamente **neste navegador**. Os dados não são sincronizados entre dispositivos.

## 💻 Executar localmente

Clone o repositório:

```bash
git clone https://github.com/KilldEmon/TATICO-FUTEBOL-BLUE-LOCK.git
cd TATICO-FUTEBOL-BLUE-LOCK
```

Abra o arquivo `index.html` em um navegador moderno. O projeto utiliza HTML, CSS e JavaScript puro, sem instalação de dependências.

## 🖼️ Imagens e créditos

As imagens dos personagens são carregadas de fontes externas, incluindo:

- [Blue Lockdle — Characters](https://bluelockdle.com/blue-lock-characters.html)
- [Blue Lock Archive — Characters](https://bluelockarchive.com/characters)

Caso uma imagem não esteja disponível, a interface pode mostrar uma imagem alternativa ou as iniciais do personagem. A disponibilidade depende dos servidores de origem.

*Blue Lock* e seus personagens pertencem aos respectivos titulares de direitos. Este é um projeto de fã, sem vínculo oficial com a franquia.
